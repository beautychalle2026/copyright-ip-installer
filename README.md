# Copyright IP Manager

Windows에서 저작물과 권리정보를 로컬로 관리하고 저작권 등록 준비를 지원하는 프로그램을 개발하고 있습니다.

**1~3단계(아키텍처·저장소·로컬 콘솔·파일 분석)를 완료했습니다. 설치 프로그램과 공식 릴리스는 아직 제공하지 않습니다.** 이 저장소는 공개 설치 안내를 위한 저장소이며 핵심 프로그램 소스는 포함하지 않습니다.

## 설치 안내

배포본이 준비되면 이 저장소의 GitHub Releases에서 Windows 설치 패키지와 무결성 검증 정보를 제공합니다. 지금은 설치 명령을 실행하지 마세요.

PC 명령을 실행할 수 있는 AI 에이전트에 설치를 맡길 때는 [AI_INSTALL.md](AI_INSTALL.md)를 사용합니다. 실행 권한이 없는 일반 채팅 사용자를 위한 원클릭 설치 프로그램도 추후 제공합니다.

## 제품 원칙

- 기본 분석과 저작물 저장은 내 PC에서 수행합니다. 외부 유료 AI API를 필수로 사용하지 않습니다.
- 저작자·권리자·창작일 등 중요한 정보는 사용자가 확인합니다.
- 본인인증·전자서명·최종 신청·결제는 사용자 통제 아래 진행합니다.
- 프로그램 운영비와 등록기관의 법정 등록 수수료는 구분합니다.
- 공식 신청서 작성·사이트 자동입력 등은 아직 개발·검증 중입니다.
